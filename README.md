## ~/about-me

I'm a systems-focused engineer who values **robustness, performance, and pragmatism** over polish. My approach to software is simple: understand the problem deeply, build something that works, and never stop iterating until it's right.

I'm currently deep in the world of **systems development** — writing low-level code, breaking it in creative ways, and debugging my way back to a working state. I don't have decades of enterprise experience, but I make up for it with relentless curiosity, stubborn persistence, and a genuine drive to build things that matter.

```bash
$ cat philosophy.txt
"I don't care about the aesthetics; I care about the job getting done."
```
